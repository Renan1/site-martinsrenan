Página inicial interativa: 3 conceitos

Protótipos para inspirar. Os projetos ficariam numa página separada ("Ver projetos →").

1 — ComandaQuadro de letras de restaurante + impressora térmica. Escolha um problema e a solução sai impressa no recibo; os pedidos antigos vão para o espeto. 2 — ScannerA página é uma mesa bagunçada de papel. O cursor/dedo é a lente do scanner e revela a versão em sistema por baixo. 3 — Patch panelPainel de rede: arraste o cabo do problema até o sistema que o resolve. LED acende, display mostra o projeto.
