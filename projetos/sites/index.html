      FICHA TÉCNICA

      Sites que atraem clientes

      Problema
      Site desatualizado não aparece na busca, demora no celular e não leva o visitante a falar com a empresa. Muitos ainda carregam rastreadores e scripts de terceiros que ninguém revisou.
      Solução
      Sites estáticos, rápidos e sem servidor: SEO local (título, descrição, dados estruturados, sitemap), contato em um toque, HTTPS forçado e só o código necessário.
      Couve Flor
      Site institucional do restaurante corporativo: dados estruturados de restaurante para o Google, Open Graph para compartilhar no WhatsApp, botão de orçamento e de WhatsApp, imagens com texto alternativo e nenhum rastreador.
      Este portfólio
      15 páginas, cada uma com interação própria, sem framework e sem build. CSP em todas as páginas, fontes e scripts só do próprio site, nenhum innerHTML com texto externo e prints de apps com dados sensíveis tarjados.
      Stack
      HTML · CSS · JavaScript puros · Schema.org (JSON-LD) · Open Graph · GitHub Pages · Cloudflare (DNS e HTTPS)
